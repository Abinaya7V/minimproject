# ML Classification Module

**Project:** AI-Powered Email Phishing Detection Chrome Extension
**Module:** ML Classification
**Status:** Complete

## What this module does

This module takes the TF-IDF numeric feature vectors produced by the NLP Preprocessing module and trains a Logistic Regression classifier on them. It does not rely on a separate Feature Extraction module; it directly learns from the textual features (words) to classify an email as either "Phishing" or "Legitimate".

## Files

| File | Purpose |
|---|---|
| `train_model.py` | Loads dataset, trains a Logistic Regression model, evaluates it, and saves the trained artifacts (`.pkl`). |
| `predict.py` | Exposes a `predict_email` function that takes raw text, runs it through the full pipeline, and outputs a structured prediction with reasons. |
| `sample_data.csv` | A tiny synthetic dataset with 20 examples created automatically for demo purposes. |
| `phishing_model.pkl` | The trained model (generated by `train_model.py`). |
| `vectorizer.pkl` | The fitted TF-IDF vectorizer (generated by `train_model.py`). |

## How to run it

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Train the model:**
   ```bash
   # You can run it without arguments to auto-generate and use sample_data.csv
   python train_model.py 

   # Or provide your own CSV dataset (needs 'text' and 'label' columns)
   python train_model.py path/to/your_dataset.csv
   ```
   *This evaluates the model and saves `phishing_model.pkl` and `vectorizer.pkl` to the current directory.*

3. **Test predictions:**
   ```bash
   # Runs a quick inline demo using predict.py
   python predict.py
   ```

## Why this design

- **Simple and Fast:** By directly coupling to the existing TF-IDF vectorizer, we eliminate the need for complex intermediate feature extraction during the demo phase.
- **Explainable output:** Even without explicit feature extraction, the `predict.py` script derives human-readable "reasons" by scanning the text for common heuristics when an email is flagged, satisfying the UI requirements.
- **Easily Extensible:** Built using `scikit-learn`'s standard APIs. The model can easily be swapped out for Random Forest, XGBoost, or integrated with additional features in the future.
